# 知识点说明

本阶段会学习：

- 项目目录为什么需要清晰分层。
- Git 仓库、工作区、暂存区和提交分别是什么。
- 为什么每次只提交一个清晰的小变化。
- 文档为什么应该和代码一起进行版本管理。

## 本次实战新增

- Python 包可以通过 `python -m relaytown` 的方式启动。
- `__main__.py` 是模块被直接运行时的入口文件。
- `main()` 函数让程序入口更清晰，也方便后续测试。
- 测试应该先描述期望行为，再编写实现代码。
- Windows 终端显示中文时，如果出现乱码，可以使用 `python -X utf8` 临时启用 UTF-8 输出。
